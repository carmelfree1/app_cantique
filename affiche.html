Recueil de cantiques

À lire sur votre téléphone, même sans connexion

appcantique.vercel.app

Sur Android

  1. Scannez le code avec l’appareil photo.
  2. Ouvrez le lien dans Chrome.
  3. Touchez Installer (ou menu ⋮ → « Installer l’application »).

Sur iPhone

  1. Scannez le code avec l’appareil photo.
  2. Ouvrez le lien dans Safari.
  3. Touchez Partager puis « Sur l’écran d’accueil ».
Important : si le lien s’ouvre dans WhatsApp, Facebook ou une autre application, l’installation est impossible. Touchez « ⋮ » (ou le bouton de partage) puis « Ouvrir dans le navigateur ». L’application fonctionne aussi sans être installée.
